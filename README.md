# ecommerce-ui-ux-design
# 🛒 ShopEase - E-Commerce UI/UX Design

## 📌 Overview
ShopEase is a modern e-commerce UI/UX design created in Figma focusing on usability, responsiveness, and clean design principles.

## 🧩 Pages Included

### 🏠 Home Page
- Hero banner
- Product categories
- Featured products

### 📦 Product Page
- Product images
- Price & ratings
- Add to cart

### 🛒 Cart Page
- Product list
- Quantity update
- Total price

### 🔐 Login Page
- Email/password login
- Signup option


## 🛠 Tools Used
- Figma
- UI/UX Design Principles
- Responsive Layout

 ##Outcome
Improved UI/UX design skills with real-world e-commerce workflow understanding.
